# News & Events 發布檢查表

> 適用於首頁 News & Events、`news.html` 與所有單篇內容。正式網站只發布已完成事實、品牌、權利及公開核准的內容；任何一項未完成都維持非公開狀態。

## 狀態流程

`草稿 → 事實查核 → 品牌／權利審核 → 核准公開 → 已發布 → 已歸檔`

| 狀態 | 進入條件 | 可否公開 |
| --- | --- | --- |
| 草稿 | 已建立台帳列與內容草稿，仍可能有待確認欄位。 | 否 |
| 事實查核 | 必要欄位齊全，逐項核對日期、名稱、數字、狀態、來源與連結。 | 否 |
| 品牌／權利審核 | 事實已確認，檢查品牌語氣、合作關係、圖片、Logo、引言、引用與商標權利。 | 否 |
| 核准公開 | 指定核准人已留下可追溯的公開核准紀錄，且沒有未結事項。 | 可排程，不代表已上線 |
| 已發布 | 頁面、列表、首頁精選、SEO 與外部連結已完成上線後檢查。 | 是 |
| 已歸檔 | 內容已過時、活動已結束、權利到期或依決策下架，並完成入口同步。 | 視歸檔政策；不得作首頁精選 |

## 1. 草稿建立

- [ ] 已在 `news-and-events-content-list.csv` 建立唯一一列，沒有重複 slug 或詳情網址。
- [ ] `category` 只使用 `company`、`project`、`event` 或 `media`。
- [ ] 標題、摘要、來源、發布日期、slug、詳情網址、事實來源、核准負責人及最後更新日期已填寫。
- [ ] 活動已填 `event_date`；非活動內容不以活動日期冒充發布日期。
- [ ] 媒體報導已填原始來源 `external_url`，並清楚標示為外部報導。
- [ ] 未知內容保留在內部待確認清單，不以推測補寫。

## 2. 事實查核

- [ ] 每個日期、數字、名稱、職稱、地點、引言與狀態都有可追溯的 `fact_source`。
- [ ] 標題與摘要沒有超出原始證據，也沒有使用 `BREAKING NEWS`、全球首發、重大突破、產業領先或創紀錄等未證實宣稱。
- [ ] 發布日期使用絕對日期，不使用「剛剛」「近期」或其他會失效的相對時間。
- [ ] 站內與外部連結可開啟，連結目的與 CTA 文字一致。
- [ ] 引言逐字核對，並有引言者及公司公開核准。

### 公司公告

- [ ] 發布主體、生效日期、影響範圍與核准來源明確。
- [ ] 一般頁面更新、內部討論或尚未生效的規劃沒有被包裝成正式公告。

### 專案動態與專案狀態

- [ ] 案場／專案名稱、資訊截至日期、所在地層級與狀態均在公開核准範圍內。
- [ ] 已清楚區分洽談／規劃、建置、試運轉、目標商轉、已商轉與已營運。
- [ ] 目標、意向、規劃容量與預計日期沒有被寫成已完成、已簽約或保證成果。
- [ ] 客戶、夥伴、專案成果及責任分工都有雙方可公開的證據。

### 活動資訊

- [ ] 活動日期、時間、時區、地點、活動狀態、主辦／協辦角色與 SiGTRON 參與方式已核對。
- [ ] 報名截止日、費用、資格及外部報名連結仍有效。
- [ ] 參展、會面或簽署意向書沒有被延伸成成交、正式合作或部署完成。
- [ ] 已設定活動結束、延期、取消或報名截止後的更新責任人與檢查日期。

### 媒體報導

- [ ] 媒體名稱、原始標題、原始刊登日期與原始來源網址一致。
- [ ] 本站摘要使用自有文字，沒有大量轉載原文。
- [ ] 摘錄、截圖、照片、媒體 Logo 與報導標題的使用符合授權及引用規範。
- [ ] 版面與文案沒有暗示媒體推薦、認證或背書。

## 3. 品牌與關係審核

- [ ] 內容符合專業、工程導向、穩健可信的語氣，不用空泛 AI 流行語取代事實。
- [ ] SiGTRON 是主品牌；SignalPro、INFINITIX 與其他組織的稱謂及角色符合已核准品牌關係。
- [ ] 合作方、客戶、供應商、主辦／協辦單位與媒體的名稱及關係描述已取得必要的雙方公開核准。
- [ ] 未將規劃、接洽、意向或目標狀態寫成正式合作、成交、部署、商轉或背書。
- [ ] CTA 只使用適合內容的 `閱讀內容`、`查看活動資訊`、`查看原始報導`，以及頁尾的 `洽談專案`／`了解 AIDC 建置`。

## 4. 圖片、Logo、人物與素材權利

- [ ] 每項圖片、Logo、截圖、影片、圖表或分享圖都已登錄於 `news-image-rights-log.csv`。
- [ ] `rights_status` 為已核准，核准用途涵蓋網站、首頁精選與社群分享等實際用途。
- [ ] 權利持有人、授權依據、必要署名、到期日及核准人可追溯。
- [ ] Logo 與商標已取得適用於本則內容的公開使用核准，並保持原比例、原色與安全留白。
- [ ] 可辨識人物已有適用的肖像／公開同意；涉及未成年人或敏感場域時已完成額外審核。
- [ ] 圖片替代文字描述可見內容，不加入圖片無法證明的成果或關係。
- [ ] 沒有使用網路抓圖、未授權素材、假活動、假機房或看似紀實的生成照片。

## 5. SEO、網址與可讀性

- [ ] SEO Title、Meta Description、canonical／正式網址與社群分享資訊均已完成。
- [ ] SEO 文案只使用已核准事實，不加入未確認的效能、價格、認證、容量、合作或成果宣稱。
- [ ] Slug 唯一、穩定且使用小寫英數與連字號；發布後非必要不更改。
- [ ] H1 唯一；標題層級、日期、來源、分類與 CTA 清楚。
- [ ] 圖片有適切替代文字；純裝飾圖使用空替代文字。
- [ ] Breadcrumb、返回消息列表與站內相關連結正確。
- [ ] 媒體報導外部連結與本站內容頁清楚區分。

## 6. 公開核准

- [ ] 事實查核人、品牌審核人、權利審核人及公開核准人／日期均已記錄。
- [ ] 合作方、媒體、講者、引言者或素材權利人的必要核准已附檔或可追溯。
- [ ] 草稿中的 `[待確認]`、`[發布前移除]`、編輯提示、註解及示意文字已全部移除。
- [ ] `status` 已由授權人更新為 `核准公開`；未核准草稿沒有被產出至正式網站。

## 7. 發布與首頁同步

- [ ] 單篇頁已建立，列表卡片的分類、日期、標題、摘要、來源、圖片與連結與單篇內容一致。
- [ ] `news.html` 依發布日期由新至舊排列，並完整保留公司公告／`company`、專案動態／`project`、活動資訊／`event`、媒體報導／`media` 四分類 filters。
- [ ] 首頁 News & Events 位於完整 `#project-footprint`（台南新市旗艦案場與亞洲 AIDC 專案布局）之後、AIDC 能力介紹之前。
- [ ] 若 `homepage_featured=yes`，該內容仍有效；首頁使用固定三則靜態精選，不使用 rail、carousel、自動播放或循環。
- [ ] 三則中至少一則為 `company` 或 `project`，`event` 最多一則；其餘內容可為 AI 雲服務更新、媒體報導或生態系合作動態，並已歸入正確分類。
- [ ] `homepage_order` 唯一且排序正確；核准內容不足三則時顯示實際則數，沒有重複內容或未核准卡片補齊版面；零則時顯示正式空狀態。
- [ ] 首頁卡片在桌機為三欄、平板為 2＋1、手機為單欄，內容順序在各斷點一致。
- [ ] 靜態原型的三張範例卡均明確標示「示意內容｜非正式發布」，且未進入正式網站、SEO sitemap 或社群分享內容。
- [ ] Footer 的「新聞與活動」、列表頁、單篇頁與 CTA 連結皆可正常到達。
- [ ] 已發布內容已納入正式 sitemap；草稿、模板與未核准頁沒有被索引。
- [ ] 發布後已在桌機與手機檢查標題換行、日期、來源、圖片裁切、替代文字與外部連結。
- [ ] `status`、`last_updated` 與實際上線日期已同步更新。

## 8. 時效、下架與歸檔檢查

- [ ] 已指定定期檢查日期與負責人，確認事實、狀態、連結與素材權利仍有效。
- [ ] 活動報名截止或結束後，已更新為 `報名截止`／`已結束`，並移除或改寫「立即報名」「即將舉辦」；活動結束後 72 小時內已從首頁精選撤下，或替換為完成事實、品牌、權利與公開核准的活動回顧。
- [ ] 活動延期或取消時，列表、單篇頁、首頁精選及外部 CTA 已同步更新。
- [ ] 專案狀態變更時保留資訊截至日期，不直接覆寫成無來源的新狀態。
- [ ] 媒體原始連結失效時已尋找媒體方正式替代網址；無法驗證時標註或歸檔，不改連至非原始轉載。
- [ ] 圖片、Logo、引言或合作公開權利到期、撤回或變更時，已立即移除或替換核准素材。
- [ ] 下架／歸檔時已從首頁精選、分類列表、站內相關連結、SEO sitemap 與社群預覽入口同步移除或更新。
- [ ] 歸檔決策、日期、原因與負責人已記錄，`status` 更新為 `已歸檔`，`archive_date` 已填寫。
