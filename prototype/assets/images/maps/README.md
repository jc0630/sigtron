## `asia-project-pipeline-map.png`

- 用途：首頁實際顯示的 994 × 860 固定合成地圖。
- 底圖沿用上述 Wikimedia Commons 素材與授權。
- 日本、台灣、泰國、菲律賓、馬來西亞及印尼的 Pin、中英文標籤與深色視覺均已直接合成在 PNG 中。
- 台灣使用琥珀色 Pin 與「旗艦案場」標籤，代表台南新市案場已進入試運轉；其他五國使用 Teal Pin，代表洽談及規劃中市場。
- 網站只顯示此單一圖片，不再使用 HTML／CSS 動態定位 Pin。
- 市場 Pin 僅代表國家層級洽談／規劃市場，不代表精確城市或案址。

不得將地圖上的 Pin 或約 800 MW 潛在總容量描述為已簽約、已部署、已建置或已投入營運。
