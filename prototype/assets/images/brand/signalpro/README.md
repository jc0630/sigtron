# SignalPro Brand Assets

本資料夾保存公司提供的七份 SignalPro PNG 原始素材。檔案均為完整複製，未重新壓縮、裁切、重繪或改色。

## 檔案與建議用途

- `signalpro-logo-horizontal-color.png`  
  彩色橫式 SignalPro Logo，適合白色或淺色背景上的品牌介紹、文件與合作關係頁面。

- `signalpro-company-lockup-color.png`  
  彩色圖形搭配「希格諾科技股份有限公司／SignalPro Technology Co., Ltd.」，適合法律公司資訊、簡報封底與正式公司介紹。

- `signalpro-symbol-color.png`  
  彩色獨立圖形標誌，適合淺色背景上的圖示、大型品牌裝飾或 Favicon 評估。

- `signalpro-symbol-white.png`  
  白色獨立圖形標誌，適合深色背景。目前已用於網站四頁底部的 `Powered by SignalPro`。

- `signalpro-company-lockup-black.png`  
  黑色公司全名版本，適合黑白列印或單色正式文件。

- `signalpro-logo-horizontal-black-alt.png`
- `signalpro-logo-horizontal-black.png`  
  兩份來源檔案內容完全相同，均予以保留，適合白底黑白應用。

## 網站使用原則

- SiGTRON 是網站主品牌；SignalPro 僅在公司關係、法律資訊與 `Powered by` 署名中出現。
- 深色頁尾優先使用白色圖形版本，不放帶白底的完整橫式圖片。
- 不在首頁 Hero 並列兩個大型 Logo，避免雙主品牌競爭。
- 所有版本保持原比例與安全留白，不自行改色或拆解重組。
