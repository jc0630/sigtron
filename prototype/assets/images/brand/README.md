# SiGTRON Brand Assets

本資料夾存放已由公司提供的 SiGTRON 品牌素材。兩份 PNG 均為原始檔的完整複製，未重新壓縮或修改。

## 檔案

- `sigtron-logo-horizontal.png`：橫式 Logo，建議用於網站導覽列、頁尾與橫向版位。
- `sigtron-logo-stacked-tagline.png`：直式 Logo，包含「算力堆疊，智慧誕生」標語，建議用於大版位、簡報、社群或品牌介紹。
- `signalpro/`：SignalPro／希格諾科技 Logo 素材庫，包含彩色、黑色、白色圖形與公司全名版本。

## 使用注意事項

- 保持原始比例，不拉伸或裁切。
- 保留透明背景與 Logo 周圍安全留白。
- 尚未取得正式品牌規範前，不自行改色、加外框、加陰影或重排標誌與文字。
- 網站小尺寸使用時優先採橫式版本；直式含標語版本不適合直接縮小放入導覽列。
